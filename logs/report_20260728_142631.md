### phase-2-a: 실제 입력값으로 Todo 항목 생성

**성공 조건**
- 입력창에 '새 테스트 할 일'을 입력하고 추가 버튼을 클릭하면 목록에 '새 테스트 할 일' 텍스트를 가진 항목이 표시된다.
- 추가된 항목의 텍스트가 입력창 placeholder인 '새 할 일을 입력하세요'가 아니라 사용자가 입력한 값으로 표시된다.
- 새 항목이 기존 목록이 있는 경우에도 목록의 최하단에 표시된다.

**최종 상태**: `gui_verified`

**개발자 코드 요약**: 제출 처리에서 placeholder 대신 입력창의 현재 값(input.value)을 읽고, 공백만 입력된 경우를 막기 위해 trim() 처리했습니다. 새 Todo는 기존 배열의 마지막에 추가되어 localStorage 저장 후 즉시 렌더링됩니다.
